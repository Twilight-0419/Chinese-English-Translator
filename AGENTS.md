# Project Instructions

## GitHub Upload Convention

The user may ask in Chinese: "请你上传github" (or similar wording about uploading to GitHub).
When that happens:

1. Read the current project folder contents.
2. Stage all changes, respecting `.gitignore` (never commit secrets, tokens, or large
   datasets/checkpoints that are ignored).
3. Create a commit with a clear, concise message describing the changes.
4. Push the current branch to the `origin` remote.
5. Report back the commit hash, the branch, and the repository URL.

Remote: `origin` points to the user's GitHub repository for this project.
