# Chinese-English Translator

A Chinese-to-English machine translation project based on a GRU sequence-to-sequence
model with an attention mechanism.

## Project Layout

```
data/       datasets and preprocessing output
models/     trained model checkpoints
notebook/   experiments and exploration
src/        source code (data pipeline, model, training, inference)
```
